| Данные | В чем необходимость защиты | Инструменты защиты |
|---|---|---|
| Личные данные пациентов | Соответствие ФЗ о защите данных, репутационные риски компании | Keyckoack, SSL/TLS |
| Медицинские карты пациентов и результаты анализов | Могут быть использованы злоумышленниками для спама, шантажа и т.п. | Keyckoack, SSL/TLS, PostgreSQL Anonymizer |
| Учет записи к специалистам и регистрация анализов | Репутационные риски, данные могут быть подменены злоумышленниками чтобы нарушить работу компании | Keyckoack, SSL/TLS, PostgreSQL Anonymizer |
| Учет денежных средств | Может быть нанесен финансовый ущерб | Keyckoack, SSL/TLS, токенизация |
| Учет ТМЦ | Может быть нанесен финансовый ущерб, данные могут быть использованы для доступа к оборудованию | Keyckoack, SSL/TLS, PostgreSQL Anonymizer |
